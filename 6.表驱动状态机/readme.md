            状态机函数指针法            状态机表驱动法
适用场景：     状态少，逻辑复杂       状态多，跳转规则清晰
代码结构：     每个状态分一组函数      逻辑转换包含表格里
维护成本：     修改逻辑修改代码         修改逻辑只修改表格
灵活性：        可以写复杂判断          只能处理离散的事件
状态出入处理：   支持                      需要额外处理

线性查表：复杂度O(n)，状态少可以使用
二维查表：复杂度O(1),建议状态多使用

注意：状态机的事件管理需要使用队列管理，处理完一个队列内容后再处理下一个，
    否则在中断发生事件会导致当前动作未执行完就执行下一个动作。
