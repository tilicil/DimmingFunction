            状态机函数指针法            状态机表驱动法
适用场景：     状态少，逻辑复杂       状态多，跳转规则清晰
代码结构：     每个状态分一组函数      逻辑转换包含表格里
维护成本：     修改逻辑修改代码         修改逻辑只修改表格
灵活性：        可以写复杂判断          只能处理离散的事件
状态出入处理：   支持                      需要额外处理


注意：函数指针状态机需要额外画出状态图，明确出各个状态模块，以及模块之间的跳转关系。

状态之间切换之后不能立即处理，任何处理都要在Run函数中统一处理。
永远不要在 OnEntry/OnExit 里立即切换状态，只能"请求"切换。
即pfun不能在状态切换中执行!!!
